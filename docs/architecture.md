# 架构与边界

## 职责

`base-authorization` 是 OpenSabre 的授权服务，负责 OAuth2/OIDC 授权、登录、客户端注册、在线用户与登录验证码能力。它不承载组织、角色和资源的主数据管理；相关用户与角色数据通过集成边界取得。

## 主要代码边界

| 区域 | 位置 | 职责 |
| --- | --- | --- |
| HTTP 入口 | `rest/` | 授权、登录验证码、在线用户和客户端管理接口 |
| OAuth2 | `oauth2/` | 授权服务器、设备授权、登录与处理器 |
| 登录安全 | `oauth2/login/` | 登录校验、用户/组织锁定策略 |
| 在线用户 | `online/` | 在线会话记录与查询 |
| 数据 | `dao/`、`entity/`、`resources/db/` | 持久化模型与初始化脚本 |

## 外部依赖

运行配置以 `application.yml`、`bootstrap.yml` 为准；数据库初始化脚本位于 `resources/db/`。不要在本文档中复制密码、客户端密钥或生产连接信息。
